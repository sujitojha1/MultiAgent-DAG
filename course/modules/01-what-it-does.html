The key insight

This agent doesn't answer in one big step. It breaks your question into a small team of specialists, runs them in order, and assembles their work into one answer — and the team is decided on the fly, per question.

The simplest run: a team of two

For a trivial "say hello," the team has just two members: a Planner who decides who's needed, and a Formatter who writes the final words.

What happens the moment you hit enter

Here is the real entry point — the few lines that run when you type the command. Read the plain-English side.

CODE 

def main() -> None:
    args = sys.argv[1:]
    resume_sid: str | None = None
    if args and args[0] == "--resume":
        resume_sid = args[1] if len(args) > 1 else None
        query = " ".join(args[2:])
    else:
        query = " ".join(args) or "Say hello in one short sentence."
    asyncio.run(Executor().run(query, session_id=resume_sid, resume=bool(resume_sid)))
PLAIN ENGLISH

This is the function that runs first.

Grab the words you typed after the command.

Make an empty slot for "pick up an old session."

If the first word is --resume...

...remember which old session to continue,

and treat the rest as your question.

Otherwise (the normal case)...

...treat everything you typed as the question, with a friendly default if you typed nothing.

Hand the question to the Executor — the showrunner that builds and runs the team — and let it work.

Two extra words worth knowing: session (a saved run you can continue) and asynchronous (it can wait on slow tasks without freezing). One mention each is plenty.

The team grows with the question

The list of team members is not fixed. The Planner sizes the crew to whatever you asked. The code never changes — only the plan does.
